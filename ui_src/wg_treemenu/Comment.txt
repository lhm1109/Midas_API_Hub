_/ inline member function ,class structure , class enumeration type에 대한 
_/ comment를 위한 중첩된 topic과 paragraph를 지정할 수 있다. 
_/ 아래 Class는 중첩된 topic 과 paragraph의 사용에 대한 예제 Class이다. 
_/
_/ Inline member function과 struructure , enumberation 은 중첩 Nested Topic tag
_/ 정의로 documentation 가능하다.  
_/
_/ Nested topic을 생성하기 위해서는 topic tag가 paragraph tag와 함께 정의 되어야 한다.
_/
_/ topic tag와 paragraph tag을 같은 위치에 정의하기 위해서는 아래 enumeration 과 
_/ structure에 대한 document tag 정의 형식으로 기술되어야 한다. 
_/ 제시된 예제의 enumeration 관련 tag에서 //emem 으로 기술된 부분을 볼 수 있는데
_/ 이것은 기술된 documentation이 main topic 의 일부분이 아니고 subtopic 즉 
_/ CompareFlags topic의 일부분임을 의미한다. 이것은 topic CompareFlags에 대한 새로운 
_/ HyperLink를 생성함을 의미한다.  structure 역시 같은 의미로 사용된다. 
_/
_/ @menum   enumeration type member data를 의미한다.
_/ @mstruct structure type member data를 의미한다.
_/ @emem은 enum member 임을 의미한다. 
_/ @field는 structure field를 의미한다.

//@class A simple string class.

class CString {

public:
  //@access Costructor & Destructor

	//@cmember,mfunc Constructor, initializes string to empty.
	CNested(void) { m_szText = NULL; }

	//@cmember,mfunc Destroys the string, if present.
	~CNested(void) { Reset(); }

	//@access Operation 
	//@cmember,mfunc Destroys the string, if present.
	void Reset(void) { if(m_szText) delete m_szText; m_szText = NULL; }

	//@cmember,menum Comparison flags for the <mf .Compare> function.
	enum CompareFlags {
    compNormal,       //emem Case-sensitive compare.
		compIgnoreCase,   //emem Case-insensitive compare.
		compFuzzy,        //emem Fuzzy compare, if words sound
	}                   // alike

	
	//@cmember,mstruct Parsing text structure
	struct MyStruct
	{
	char *szBase;		//field Base of text to parse
	char *szCur;		//field Current parsing location
	};
	
	//@cmember Comparison function.

	int Compare(const char *szCompText, int nCompFlags = 0);

	//@cmember Sets the text of the string.

	void Set(const char *szText);

private:
	//@cmember Pointer to string text.

	char *m_szText;
}
